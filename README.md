Pasos para ejecutar y usar esta herramienta:

1. Instala las dependencias necesarias:
Este script utiliza la librería externa `colorama` además de módulos nativos. Instálala ejecutando en tu terminal:
pip install colorama


2. Lanza el script: Ejecuta el archivo desde tu consola con el comando:
python main.py
